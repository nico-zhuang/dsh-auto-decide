# dsh-auto-decide

DSH 0.2.1-rc.2 的普通 `ask_user_question` 超时处理插件：默认启用、全局模式、120 秒后跳过；可在「插件 → 已安装插件 → dsh-auto-decide → 组件配置」修改为 1–3600 秒（例如 5 秒）、切换为唯一推荐项模式，或限制到指定会话。配置由 DSH Config Forms 持久化，升级旧版会保留全局行为。

## 会话范围

- **全局（默认）**：所有当前和以后新建的会话都使用插件，兼容 0.1.1 原有行为。
- **白名单**：仅在勾选并保存的会话生效；新会话默认不在名单中，空名单表示全部由用户回答。推荐项模式优先使用白名单。
- **黑名单**：勾选并保存的会话始终由用户回答，其余会话生效；以后新建的会话也会生效，空名单等同全局。请特别注意重要的新会话。

组件配置中先选工作范围，再按会话标题或 ID 搜索、多选并单击「保存已选会话」。可显示已归档会话；名单只保存稳定会话 ID，不按可变标题匹配。已选但目录不再显示的会话可从名单中移除。模式或名单在一个问题等待期间变更时，旧计时器不会沿用先前规则自动作答；不在范围内的普通问题从一开始交由原本人工应答界面处理。全局模式仍保留已保存的名单，切回白/黑名单时恢复。

## 处理范围与安全边界

- `skip`：整批普通问题到时都返回 `{selected:[]}`；**跳过不是同意**。
- `recommended`：**仅对题干和推荐选项均明确属于展示／外观／格式／语言类**的单选题匹配标签末尾唯一的 `(Recommended)`；陌生领域、多选、缺失/重复推荐项或涉及部署、发布、删除、支付、授权、同意、分享、发送、写入等敏感动作时一律回退跳过。不猜测第一个选项，也不提供通用自动批准。
- 仅处理来自模型工具 `ask_user_question` 且属于确切 live agent 的请求。带 `intent`/`detail` 的计划审阅和独立的安全审批渠道不会自动应答。真人抢先回答时优先真人；插件停用或等待中改配置后不沿用旧自动规则。
- 自动结果在下一步 Agent 上下文明确标记插件来源、`humanConfirmed: false`、选择与“跳过非同意”。不伪装为用户对外操作的授权。

**限制：**敏感词过滤不是语义安全审查；推荐模式需使用者主动启用。Host 自行计时，与 DSH `timed` 问题策略不同；更短的宿主定时器或直接关闭插件可能改变结果。插件不会代替用户处理计划审阅或安全审批。

## 安装、测试与回滚

通过 DSH 侧栏「插件 → 添加插件」安装已发布 GitHub 标签 `github:nico-zhuang/dsh-auto-decide#v0.2.0`；按安装器提示启用。升级旧版时走插件管理器的卸载／安装流程，不直接改 profile 文件。若提示重启，须重启当前桌面宿主，单纯刷新浏览器不够。安装后从组件配置页调整开关、范围、名单、模式和秒数，再用普通无风险问题确认推荐、回退跳过和来源说明。测试不可用真实发布、删除或支付操作。

本地开发运行：

```bash
npm install --ignore-scripts
npm test
npm run check
```

回滚请使用 DSH 插件管理器先停用或卸载 `dsh-auto-decide`，不手工修改 profile 清单、Cordis patch 或应用包。
